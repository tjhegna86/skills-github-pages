# Setting Up GitHub

## Learning How GitHub Is Teaching Me to Be a Builder

When I started working through the GitHub tutorials, I expected to learn a little bit about coding. What I didn’t expect was realizing that GitHub isn’t really teaching me how to *code* — it’s teaching me how to *build*.

Before writing a single line of code, GitHub is showing me the structure behind real projects. I’m learning how repositories work, how files are organized, how changes are tracked, and how documentation ties everything together. These are the foundations every builder needs long before the actual coding begins.

Every small step — creating a repository, editing a file, publishing a page — teaches me how to think like someone who builds things. GitHub makes the process approachable, letting me learn by doing instead of overwhelming me with technical details. It’s not about becoming a developer overnight; it’s about understanding the environment where building happens.

GitHub is giving me the mindset, the tools, and the workflow of a builder. Coding will come later. Right now, I’m learning how to create, organize, publish, and iterate — and that’s the part that matters most at the beginning.

---

## Why I’m Setting Up GitHub

I’m building a foundation for everything I want to create: AI tools, automation systems, digital products, and small experiments that help me learn. GitHub Pages is part of that foundation. It gives me a simple way to publish content, document my progress, and share what I’m working on — even if the projects are still early or imperfect.

Having a place to store my ideas and prototypes matters. It keeps me accountable. It gives me a home base for my work. And it lets me see my growth over time, commit by commit.

---

## What I Learned Today

- How to create and edit files in a repository  
- How GitHub Pages uses `index.md` or `README.md` as a homepage  
- How commits act like snapshots of your progress  
- How Markdown makes writing clean and structured without needing a full website builder  

These might seem like small things, but together they form the foundation of understanding how GitHub works. Once you understand the basics, everything else becomes a little less intimidating.

---

## Why This Matters

I’m not trying to become a full-time developer — I’m trying to become someone who can build. GitHub gives me the tools to do that, even if I’m learning one small piece at a time. It’s teaching me how to organize my ideas, track my progress, and publish my work in a way that feels real.

And honestly? It feels good to see something I wrote appear on a real webpage. It’s a reminder that progress doesn’t have to be perfect — it just has to be visible. Every commit is a step forward, and every page I publish is proof that I’m learning, experimenting, and moving toward the things I want to create.
